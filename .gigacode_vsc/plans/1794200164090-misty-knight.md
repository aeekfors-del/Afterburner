## Architecture

```
Afterburner.exe (single process)
|
+-- QApplication (Qt event loop)
    |
    +-- SystemTrayIcon (tray icon)
    |   +-- Left click -> show/hide PopupWidget
    |   +-- Right click -> menu (Settings, Exit)
    |   +-- Alert animation (blink on warnings)
    |
    +-- PopupWidget (metrics popup window)
    |   +-- Left Gauge: CPU (usage %, temp, clock, cores)
    |   +-- Right Gauge: GPU (usage %, temp, VRAM, power)
    |   +-- Center Panel: RAM, Fans, Disk, Uptime with bars
    |   +-- Bottom Bar: system info
    |   +-- Settings control which metrics visible
    |
    +-- SettingsDialog (settings dialog)
    |   +-- Tab "Metrics" (checkboxes for each metric)
    |   +-- Tab "Thresholds" (warn/crit limits)
    |   +-- Tab "System" (auto-start, notifications)
    |   +-- Apply / Cancel buttons
    |
    +-- DataCollectorThread (background data collection)
    |   +-- CPU: usage, cores, threads, temp, freq, power
    |   +-- GPU: usage, temp, VRAM, power (NVML -> WMI fallback)
    |   +-- RAM: total, used, pct, speed
    |   +-- Fans: name + RPM
    |   +-- Disk: total, used, pct
    |   +-- Uptime: days + hours
    |
    +-- AlertChecker (threshold checker)
        +-- CPU temp > warn/crit -> notification
        +-- GPU temp > warn/crit -> notification
        +-- CPU/GPU/RAM usage > warn -> notification
        +-- 30s cooldown between notifications
```

## Implementation Plan

### Step 1: Cleanup and Refactor
- Remove duplicate DataCollectorThread and NotificationManager
- Replace CONFIG with config (single variable)
- Remove QMainWindow - not needed for service
- Keep all widgets (CircularGauge, Sparkline, InfoCard, MainChart)

### Step 2: SystemTrayIcon and PopupWidget
- Create SystemTrayIcon with emoji icon as fallback
- Create PopupWidget - borderless QWidget, semi-transparent, topmost
- PopupWidget contains same widgets as MainWindow but compact
- Left click on tray -> show/hide PopupWidget
- PopupWidget auto-hides on focus loss

### Step 3: PopupWidget Layout (MSI Afterburner style)

Width: 800px, Height: 450px

Left Gauge (CPU):
- Outer ring: usage percentage (0-100%)
- Center top: usage % (large digital)
- Center middle: temperature
- Center bottom: clock speed
- Small text: cores/threads

Right Gauge (GPU):
- Outer ring: usage percentage (0-100%)
- Center top: usage % (large digital)
- Center middle: temperature
- Center bottom: VRAM used/total
- Small text: power consumption

Center Panel:
- RAM usage with progress bar
- Fan speeds
- Disk usage
- Power estimate
- Uptime

Bottom Bar:
- Mini sparklines for CPU, GPU, RAM history

### Step 4: SettingsDialog
- Three tabs: Metrics, Thresholds, System
- Metrics tab: checkboxes for each metric (CPU usage/temp, GPU usage/temp, RAM, Fans, Power, Disk, Uptime)
- Thresholds tab: spinbox for warn/crit thresholds
- System tab: auto-start, notifications, update interval
- Save to ~/.afterburner_config.json
- Apply changes in real-time

### Step 5: Notifications
- Replace empty _show_notification with working PowerShell
- Use subprocess.run(['powershell', '-Command', ...])
- Three levels: info, warning, critical
- Cooldown between same notifications

### Step 6: Auto-start
- Registry: HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Afterburner
- Read exe path via sys.executable

### Step 7: Testing and Build
- Run python monitor.py - check tray
- Show PopupWidget - check metrics
- Settings - check checkboxes
- build.bat - compile .exe

## Key Decisions

1. Single file - everything in monitor.py, no imports from other files
2. PopupWidget borderless - Qt.FramelessWindowHint + Qt.Tool, semi-transparent
3. Auto-hide - PopupWidget hides on click outside
4. Dynamic UI - settings add/remove widgets in real-time
5. PyInstaller - --onefile --windowed to hide console
6. Fallback icon - emoji if no .ico file

## Risks

1. PyQt6 in background - PopupWidget must work with minimized app
2. Windows DPI - widget scaling on different screens
3. NVML - may not work on AMD/Intel GPU, needs reliable fallback
4. PowerShell notifications - may be blocked by group policies
